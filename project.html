New Work

Additional Features

These screenshots highlight the newest admin visualization work added to the project.

  1. 2/11/26 Tyler Repo setup and Docker foundation

    This update established the project’s working base and made the repository easier to run locally.

    • Added a .gitignore and removed files that should not be tracked.
    • Added Docker support with a Dockerfile and docker-compose.yml.
    • Added documentation, Django project files, CSV data, media images, and updated README.md.
  2. 2/13/26 Tyler Docker fixes and local setup guide

    This round refined the local development workflow and made the project easier to configure safely.

    • Fixed Dockerfile and compose issues and updated the gitignore.
    • Upgraded the base Python image from 3.9 to 3.11.
    • Updated timezone settings, removed compiled cache and db.sqlite3, and added a local setup guide.
    • Expanded setup instructions for running Django on the host with the database in Docker.
  3. 2/20/26 Greg Name display fix and local SQL copy

    This update corrected a display bug and added a clean local database copy for development and testing.

    • Fixed the issue where some member names were showing as “None.”
    • Improved name assembly logic using filtered name parts.
    • Added a large SQL file, local_copy_clean.sql, for development and testing.
  4. 3/9/26 Henry Admin list improvements and filters

    This change made the Django admin members page more useful by exposing more data and filters.

    • Expanded admin list_display with religion, nationality, race, ethnicity, county, and country.
    • Added matching admin-side filters to speed up searching and review.
  5. 3/25/26 Tyler Automated test coverage and developer documentation

    Added initial automated test coverage and documentation for developers, including important notes about the admin "honeypot" login behavior to prevent lockouts.

    • Updated LocalDevSetup.md with honeypot login warning.
    • Added tests for preprocess_date_ranges (fallback, gap handling, sorting/merging).
    • Expanded AdvancedSearchDoc.md with steps to re-enable demographic filters.
  6. 4/7/26 Tyler Improved search and member results display

    Fixed a search issue when users type full names by splitting queries into terms and requiring each term to match name fields. Also removed the 8-result limit from the members page.

    • Updated search logic to match first/last/pen name fields separately.
    • Removed result slicing to show all member search results.
    • Expanded test coverage with MembersSearchTests.
    • Removed local_copy_clean.sql from repository for cleanup.
  7. 4/7/26 Tyler Django admin membership statistics and analytics

    Added a new Django admin page that calculates and displays average membership length based on members' date ranges.

    • Created MembershipStatistics proxy model.
    • Added logic to parse YYYY-YYYY date ranges and compute durations.
    • Built custom admin template showing aggregate averages.
  8. 4/7/26 Tyler Proposer relationship visualization graph

    Introduced an interactive admin visualization for proposer relationships using a directed graph. Includes name normalization and a minimum component size filter to reduce noise.

    • Added ProposerGraph proxy model.
    • Built vis-network interactive graph with nodes/edges from proposer data.
    • Implemented name normalization and variant handling.
    • Added custom admin template for graph visualization.
  9. 4/15/26 Tyler Django 5.2.12 upgrade and dependency updates

    Upgraded the project to Django 5.2.12 with all compatible dependencies. Updated settings for the new django-axes backend and cleaned up legacy configurations.

    • Bumped Django 4.2.7 → 5.2.12 in requirements.txt.
    • Updated axes, ckeditor, import-export, and easy-thumbnails.
    • Removed legacy apps: image_cropping, django_pandas, and AxesMiddleware.
    • Updated AUTHENTICATION_BACKENDS in settings.
    • Added migration for MembershipStatistics and ProposerGraph proxy models.
  10. 4/19/26 Henry Excel export functionality for admin members page

    Added an Excel export action to the Django admin "Members" and "Honorary Members" pages, allowing admins to download data in spreadsheet form.

    • Added export_model_with_related_objectsJSON (renamed/retitled).
    • Added export_model_with_related_objectsEXCEL_MERGED to merge Member rows with related Date rows.
    • Enabled formats: JSON, XLSX, CSV, XLS.
    • Uses pandas, json_normalize, and openpyxl for spreadsheet generation.
  11. 4/24/26 Tyler Removed non-functional XLS export option

    Cleaned up admin export options by removing the legacy .xls format that was not working correctly.

    • Dropped XLS from export formats in swj/admin.py.
    • Retained export formats: JSON, XLSX, CSV.
  12. 4/24/26 Tyler Merge "wishlist items" and Django upgrade

    Merged multiple "wishlist" improvements including the Django 5.2.12 upgrade, improved member search, proposer graph, and membership statistics features.

    • Integrated Django upgrade and dependency updates.
    • Added ProposerGraph and MembershipStatistics proxy models.
    • Improved multi-word member search matching.
    • Removed the "only show 8 results" limit.
    • Added new admin analytics pages for relationships and statistics.
  13. 4/24/26 Tyler Added Member.other_profession field and search

    Added a new other_profession field to the Member model and integrated it through the admin and CSV import pipeline for storage and searching.

    • Added other_profession field to swj/models.py.
    • Created migration swj/migrations/0005_member_other_profession.py.
    • Updated swj/admin.py and import_members.py for CSV pipeline.
    • Added unit tests to ensure field persists correctly.
    • Merged PR #5: "search-by-other-profession" feature branch.
